## The order model

The order model contains all the information about your orders, including the order details, customer information, line items, and tax information.

### Properties

| Name | Type | Description |
| --- | --- | --- |
| `id` | `string` | Unique identifier for the order (starts with `order_`). |
| `resource` | `string` | The resource type. Always `order`. |
| `customerId` | `string \| null` | ID of the customer who made this purchase. Always present, but `null` for orders with no associated customer. |
| `testmode` | `boolean` | Whether this order is in test mode. |
| `metadata` | `object \| null` | Arbitrary key-value metadata for your application. |
| `paymentMethod` | `string \| null` | Payment method used for this order (e.g., `ideal`, `creditcard`, `bancontact`, `paypal`). |
| `status` | `string` | The current status of the order. Can be `created`, `pending`, `paid`, `canceled`, or `expired`. |
| `cancellationReason` | `string \| null` | Why the order was canceled. `null` unless `status` is `canceled`, and `null` for orders canceled before this field existed. Currently `payment_failure` (payment recovery for this unpaid order was exhausted). |
| `invoiceNumber` | `string \| null` | Invoice number for this order (assigned after payment). |
| `total` | `Money` | Total amount including taxes. A Money object with `value` (decimal string) and `currency` (ISO 4217 code). |
| `subtotal` | `Money` | Subtotal amount before taxes. |
| `reversedSubtotal` | `Money` | Amount of the captured payment already returned to the customer, before taxes, via refund or chargeback (settled). |
| `refundableSubtotal` | `Money` | Remaining amount that can still be refunded, before taxes. Always zero for an order that is not a sale (any order type other than `checkout_order` and `mandated_order`, such as a payment-method authorization or a verification charge), because such orders cannot be refunded. |
| `taxSummary` | `array` | Tax breakdown by rate. Each item contains a `taxRate` object (`name`, `percentage`, `taxablePercentage`) and an `amount` Money object. |
| `lines` | `array` | Array of line items in this order. See OrderLine properties below. |
| `discounts` | `array` | Every discount on the order, each listed once with the amount it takes off all lines added up, in the order it first appears on the lines. Empty when the order has no discount. Match an entry to its share on each line by `id`. See Discount properties below. |
| `customerDetails` | `BillingDetails` | Customer billing details (buyer). Includes `fullName`, `companyName`, `taxId`, `streetAndNumber`, `streetAdditional`, `city`, `region`, `postalCode`, `country`, and `email`. |
| `createdAt` | `string` | When this order was created (ISO 8601 format). |
| `links` | `object` | HATEOAS links to related resources. Contains `self`, `customer` (`null` for orders without a customer) and `customerInvoice`, the invoice in the customer portal (`text/html`). On a refund or chargeback order, `customerInvoice` opens the credit note. The link is signed and expires after 72 hours; the customer can request a new one from the page. |


### OrderLine Properties

| Name | Type | Description |
| --- | --- | --- |
| `id` | `string` | Unique identifier for this line item (starts with `order_item_`). |
| `resource` | `string` | The resource type. Always `orderline`. |
| `description` | `string` | Description of the item. |
| `quantity` | `integer` | Number of units. |
| `basePrice` | `Money` | Price per unit before discounts, on the product's tax basis: excluding taxes for tax-exclusive products, including them for tax-inclusive products. |
| `total` | `Money` | Total price including taxes, after discounts (subtotal + taxes). |
| `subtotal` | `Money` | Subtotal excluding taxes, after discounts. |
| `taxes` | `array` | Tax breakdown by rate for this line. Each item contains a `taxRate` object and an `amount` Money object. |
| `discounts` | `array` | This line's share of each discount, in the order they apply. Empty when the line has no discount. `subtotal`, `taxes` and `total` are already net of these discounts. See Discount properties below. |
| `productType` | `string \| null` | The product type this line links to. One of `one_off_product`, `subscription_plan`, `subscription`, `billing_details_verification`, `auth_request_product`, or `null` when the line has no product link. |
| `productId` | `string \| null` | The linked product's id (e.g. `subscription_...` for a `subscription` line). `null` when the line has no product link. |


### Discount Properties

A discount applied to an order, as listed under the order's and each line's `discounts`. Discounts are set when [creating a checkout](/api-reference/checkouts#discounts). Amounts exclude VAT; the line's `taxes` already reflect the discount.

| Name | Type | Description |
| --- | --- | --- |
| `id` | `string \| null` | Identifies this discount on this order. Every line's share of a discount and the order's entry for it carry the same id. It names one application, not a reusable coupon: every order, and every subscription renewal, gets new ids. `null` only on discounts applied before ids were introduced. |
| `description` | `string \| null` | The label sent with the discount, if any. |
| `discountType` | `string \| null` | How the discount is defined: `percentage` or `fixed_amount`. More values may be added; treat an unknown value as a discount of an unknown kind. `null` only on discounts applied before it was recorded. |
| `percentage` | `string \| null` | The percentage taken off, as a decimal string (e.g. `"20.00"`), for a `percentage` discount. `null` for a `fixed_amount` discount. |
| `amount` | `Money` | The amount taken off, excluding VAT, also when the products' prices include VAT: €10.00 off a €121.00 price at 21% reads `8.26`. |

## List all orders

`GET /v1/orders`

This endpoint allows you to retrieve a paginated list of all your orders. By default, a maximum of ten orders are shown per page.

### Optional parameters

| Name | Type | Description |
| --- | --- | --- |
| `limit` | `integer` | The number of orders to return (default: 10, max: 100). |
| `startingAfter` | `string` | A cursor for use in pagination. Returns results after this order ID. |
| `endingBefore` | `string` | A cursor for use in pagination. Returns results before this order ID. |

::code-group{sync="api"}

```bash [cURL]
curl -G https://api.vatly.com/v1/orders \
  -H "Authorization: Bearer live_your_api_key_here" \
  -d limit=10
```

```php [PHP]
$vatly = new \Vatly\API\VatlyApiClient();
$vatly->setApiKey('live_your_api_key_here');

$orders = $vatly->orders->page();
```

## Create invoice update link

`POST /v1/orders/:orderId/invoice-update-link`

Creates a signed link to this order's invoice page, where the billing details printed on the invoice can be corrected: name, company name, street, city and region, and the invoice note. It does not change the VAT number, postal code or country, which decide the tax charged. The link is valid for 72 hours. While your account is suspended, it opens the invoice read-only.

### Parameters

| Name | Type | Description |
| --- | --- | --- |
| `orderId` | `string` | The unique identifier of the order. |

::code-group{sync="api"}

```bash [cURL]
curl -X POST https://api.vatly.com/v1/orders/order_Hn5xWqVfKm8RjTgYbUcP/invoice-update-link \
  -H "Authorization: Bearer live_your_api_key_here"
```

```php [PHP]
$vatly = new \Vatly\API\VatlyApiClient();
$vatly->setApiKey('live_your_api_key_here');

$link = $vatly->orders->createInvoiceUpdateLink('order_Hn5xWqVfKm8RjTgYbUcP');
```

```json [Response]
{
  "href": "https://billing.vatly.com/invoices/order_Hn5xWqVfKm8RjTgYbUcP?editable=1&expires=1767225600&grant=merchant&signature=3f6c0b9e...",
  "type": "text/html"
}
```
