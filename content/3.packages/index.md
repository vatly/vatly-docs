> Official Vatly packages for your language or framework.

Vatly provides official packages to integrate billing, subscriptions, and tax compliance into your application.

## Available packages

| Language / Framework | Package | Install |
| --- | --- | --- |
| PHP 8.0+ | [vatly-api-php](/packages/php/readme) | `composer require vatly/vatly-api-php` |
| Laravel 11+ | [vatly-laravel](/packages/laravel/readme) | `composer require vatly/vatly-laravel` |
| JavaScript / TypeScript | [@getvatly/sdk](https://www.npmjs.com/package/@getvatly/sdk) · [Docs](/packages/javascript/readme) · [GitHub](https://github.com/vatly/vatly-api-js) | `npm install @getvatly/sdk@alpha` |
| JavaScript / TypeScript (fluent) | [@getvatly/fluent](https://www.npmjs.com/package/@getvatly/fluent) · [Docs](/packages/fluent-js/readme) · [GitHub](https://github.com/vatly/vatly-fluent-js) | `npm install @getvatly/fluent@alpha` |

The JavaScript / TypeScript packages are in alpha. Every alpha release may include breaking changes. Pin exact versions during alpha.
