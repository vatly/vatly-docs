> **Alpha — under active development. Every alpha release may include breaking changes. Pin exact versions during alpha.**

Use Fluent for a billing integration; use the raw SDK for direct API calls. Fluent
depends on `vatly-api-python==0.1.0a2` and Python 3.10+. Follow the [quick start](https://github.com/vatly/vatly-fluent-python/blob/main/README.md)
for your first hosted checkout, then add storage for signed events and ownership.

| Guide | Responsibility |
| --- | --- |
| [Configuration](/packages/fluent-python/configuration) | Keys, lifecycle, dependency bootstrap, release |
| [Core concepts](/packages/fluent-python/coreconcepts) | Driver contracts, entities, scope and transactions |
| [Checkouts](/packages/fluent-python/checkouts) | One-off/mixed/subscription builders and retries |
| [Customers](/packages/fluent-python/customers) | Billing identity and immutable bindings |
| [Customer portal](/packages/fluent-python/customerportal) | Short-lived hosted portal sessions |
| [Subscriptions](/packages/fluent-python/subscriptions) | Swaps, cancellation, state, reconciliation |
| [Orders](/packages/fluent-python/orders) | Lines, money and reversals |
| [Webhooks](/packages/fluent-python/webhooks) | Signed snapshots, atomic processing and outbox |
| [Testing](/packages/fluent-python/testing) | SQLite example, mock transport and local checks |
| [Porting](/packages/fluent-python/porting) | Source provenance and intentional differences |

Pushes to `main` affecting `docs/**` notify `vatly/vatly-docs`, which imports
these guides automatically. The notifier requires the Actions secret
`VATLY_DOCS_DISPATCH_TOKEN` with Contents: write access to `vatly/vatly-docs`.
