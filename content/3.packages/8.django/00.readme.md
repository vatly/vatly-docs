Add hosted checkout, customer billing and signed webhook persistence to Django.
Vatly is the European Merchant of Record for AI, software and digital products.
This package builds on Fluent Python and the Python SDK.

**Alpha — under active development. Every alpha release may include breaking changes. Pin exact versions during alpha.**

## Start here

```bash
python -m pip install vatly-django==0.1.0a2
```

Follow [Installation](/packages/django/installation) to add the app, URLs and database tables,
then configure a server-owned product offer and add a checkout form. You do not
need a custom user model: the `Billing` facade accepts any saved Django model.

| Guide | Task |
| --- | --- |
| [Installation](/packages/django/installation) | Install, connect URLs and run migrations |
| [Configuration](/packages/django/configuration) | Set credentials, offers and tenant scope |
| [Billable models](/packages/django/billablemodels) | Add billing helpers to your user or team model |
| [Checkout](/packages/django/checkout) | Start a purchase with a durable retry key |
| [Customer portal](/packages/django/customerportal) | Open hosted billing for an authorized customer |
| [Subscriptions](/packages/django/billing) | Inspect, cancel, resume and reconcile owned subscriptions |
| [Webhooks](/packages/django/webhooks) | Verify, deduplicate and persist deliveries atomically |
| [Admin](/packages/django/admin) | Inspect billing records without editing them |
| [Testing](/packages/django/testing) | Exercise checkout and signed webhooks offline |
| [Development](/packages/django/development) | Run contributor checks and understand release tooling |

Python 3.10+; Django 5.2 LTS, 6.0 and 6.1 within their supported Python ranges.
Code samples are executed with the published `0.1.0a2` packages and local fixtures.
See the [API reference](https://docs.vatly.com/api-reference) for Vatly's fields.
